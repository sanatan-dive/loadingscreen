# Cutscene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a web app where a user uploads one photo and gets a 15-second GTA-style cinematic intro with their face in it, in about nine seconds.

**Architecture:** Seven decoupled modules behind a thin API. The video template is fixed data — three reference frames, a measured pan, two crossfades — so the only per-user work is swapping a face into three stills, done in parallel. Every generated face passes an identity gate before compositing, because the image models silently return wrong faces. Two cache layers keep music changes free.

**Tech Stack:** Next.js 15 (App Router) · TypeScript · Vercel · Supabase (Postgres + Storage) · onnxruntime-node (YuNet + SFace) · ffmpeg-static · OpenRouter (gemini-3.1-flash-lite-image) · Vitest · Tailwind

**Spec:** `docs/superpowers/specs/2026-09-18-cutscene-design.md`

## Global Constraints

Copied verbatim from the spec. Every task's requirements implicitly include these.

- Output video: **960×720, 24fps, exactly 15.000s**, h264 `yuv420p`, `+faststart`
- Shot duration `D = 17/3 s` (5.667s); crossfade `X = 1.0s`; total `3D − 2X = 15.000s`
- Crossfade offsets: **4.667s** and **9.333s**
- Pan: **pure horizontal, 8.7 px/s, zero vertical, zero zoom**
- Source frames upscaled to **1056×792** before the pan crop; generated shots must be ≥1056×792
- Identity threshold: `cosine(result, user) >= 0.55` AND `> cosine(result, original)`
- SFace documented same-identity threshold: **0.363** (we use the stricter 0.55)
- Model ladder: `google/gemini-3.1-flash-lite-image` → `google/gemini-3.1-flash-image` → `google/gemini-3-pro-image`
- Max **3** swap attempts per shot; on total failure the user is **not** charged
- Audio normalized to **−14 LUFS / −1.5 dBTP**, 0.6s fade in, 1.5s fade out
- Provider API keys are **server-side only**; the browser never calls a provider
- Uploads: single detectable face required, size and MIME validated, auto-deleted on a timer
- UI is **light mode**, mobile-first, four screens, no navigation chrome
- Thread/concurrency safety: **never share an ONNX session's mutable input-size state across concurrent work**

```ts
import * as ort from 'onnxruntime-node'
import { letterbox, alignCrop, nms } from './preprocess'

export const SAME = 0.363          // SFace documented same-identity threshold
export const GATE = 0.55           // our stricter production bar

export interface Face {
  x: number; y: number; w: number; h: number
  landmarks: number[]              // 10 values: reye, leye, nose, rmouth, lmouth
  score: number
}

let detSession: ort.InferenceSession | null = null
let recSession: ort.InferenceSession | null = null

async function detector() {
  detSession ??= await ort.InferenceSession.create('models/yunet.onnx')
  return detSession
}
async function recognizer() {
  recSession ??= await ort.InferenceSession.create('models/sface.onnx')
  return recSession
}

/**
 * Sessions are reused but input size is passed per-run, never stored on the
 * session. This is the fix for the race that made parallel detection return
 * spurious empty results.
 */
export async function detect(rgb: Uint8Array, w: number, h: number): Promise<Face[]> {
  const s = await detector()
  const { data, scale, padX, padY } = letterbox(rgb, w, h, 320, 320)
  const out = await s.run({ input: new ort.Tensor('float32', data, [1, 3, 320, 320]) })
  return nms(out, scale, padX, padY).sort((a, b) => b.w * b.h - a.w * a.h)
}

export async function embed(rgb: Uint8Array, w: number, h: number): Promise<Float32Array | null> {
  const faces = await detect(rgb, w, h)
  if (faces.length === 0) return null
  const s = await recognizer()
  const chip = alignCrop(rgb, w, h, faces[0])      // 112x112 aligned
  const out = await s.run({ input: new ort.Tensor('float32', chip, [1, 3, 112, 112]) })
  return out[Object.keys(out)[0]].data as Float32Array
}

export function cosine(a: Float32Array | null, b: Float32Array | null): number {
  if (!a || !b) return NaN
  let dot = 0, na = 0, nb = 0
  for (let i = 0; i < a.length; i++) { dot += a[i] * b[i]; na += a[i] ** 2; nb += b[i] ** 2 }
  const d = Math.sqrt(na) * Math.sqrt(nb)
  return d === 0 ? NaN : dot / d
}
```

`lib/identity/preprocess.ts` implements `decodePng`, `letterbox`, `nms`, `alignCrop`. Port the geometry directly from `spike/identity.py` and `spike/masked_swap2.py` — the alignment is a **uniform scale plus translate, never a stretch**:

```ts
export function similarityTransform(from: Face, to: Face) {
  const s = ((to.w / from.w) + (to.h / from.h)) / 2
  return {
    scale: s,
    tx: (to.x + to.w / 2) - s * (from.x + from.w / 2),
    ty: (to.y + to.h / 2) - s * (from.y + from.h / 2),
  }
}
```

`lib/provider/index.ts`:

```ts
import type { EditRequest, EditResult } from './types'
export * from './types'

export const MODEL_LADDER = [
  'google/gemini-3.1-flash-lite-image',
  'google/gemini-3.1-flash-image',
  'google/gemini-3-pro-image',
] as const

const ENDPOINT = 'https://openrouter.ai/api/v1/chat/completions'
const MAX_CONCURRENT = 6
let inFlight = 0
const queue: (() => void)[] = []

async function acquire() {
  if (inFlight >= MAX_CONCURRENT) await new Promise<void>((r) => queue.push(r))
  inFlight++
}
function release() {
  inFlight--
  queue.shift()?.()
}

/** Expression is authored template data. Magnitude wording is load-bearing. */
export function buildPrompt(expression: string): string {
  return [
    'You are performing a FACE REPLACEMENT edit. Two inputs:',
    'IMAGE A (first) = the scene. IMAGE B (second) = the identity to insert.',
    '',
    "Replace the man's face, hair and neck in IMAGE A with the man from IMAGE B. The output MUST",
    'clearly be the man from IMAGE B: his exact bone structure, his exact skin tone, his hair, his',
    'beard, his eye colour. Do not blend the two men. Do not darken or lighten his skin to match IMAGE A.',
    '',
    `Give him this facial expression: ${expression}.`,
    'This expression is required - do not render him neutral, deadpan or serious.',
    '',
    'Keep from IMAGE A only: the clothing, the background, the head angle, the lighting direction,',
    'the framing.',
    'Photorealistic, matching grain. No text.',
  ].join('\n')
}

const dataUrl = (b: Buffer) => `data:image/png;base64,${b.toString('base64')}`
const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms))

export async function edit(req: EditRequest): Promise<EditResult> {
  const key = process.env.OPENROUTER_API_KEY
  if (!key) throw new Error('OPENROUTER_API_KEY missing')

  await acquire()
  const started = Date.now()
  try {
    for (let attempt = 0; attempt < 4; attempt++) {
      const res = await fetch(ENDPOINT, {
        method: 'POST',
        headers: { Authorization: `Bearer ${key}`, 'Content-Type': 'application/json' },
        body: JSON.stringify({
          model: req.model,
          modalities: ['image', 'text'],
          messages: [{ role: 'user', content: [
            { type: 'text', text: buildPrompt(req.expression) },
            { type: 'image_url', image_url: { url: dataUrl(req.crop) } },
            { type: 'image_url', image_url: { url: dataUrl(req.face) } },
          ]}],
        }),
      })

      if (res.status === 429 || res.status >= 500) {
        await sleep(2 ** attempt * 500 + Math.random() * 300)   // backoff + jitter
        continue
      }
      if (!res.ok) throw new Error(`provider ${res.status}: ${await res.text()}`)

      const body = await res.json()
      const url = body?.choices?.[0]?.message?.images?.[0]?.image_url?.url
      if (!url) throw new Error('provider returned no image')

      return {
        image: Buffer.from(url.split(',')[1], 'base64'),
        model: req.model,
        ms: Date.now() - started,
        costUsd: body?.usage?.cost ?? 0,
      }
    }
    throw new Error('provider exhausted retries')
  } finally {
    release()
  }
}
```

```ts
export interface GateInput { vsUser: number; vsOriginal: number }
export interface GateResult {
  pass: boolean; reason?: string; vsUser: number; vsOriginal: number
}

export function verify({ vsUser, vsOriginal }: GateInput): GateResult {
  const base = { vsUser, vsOriginal }
  if (Number.isNaN(vsUser) || Number.isNaN(vsOriginal))
    return { ...base, pass: false, reason: 'no face detected in result' }
  if (vsOriginal >= vsUser)
    return { ...base, pass: false, reason: 'result resembles the original subject, not the user' }
  if (vsUser < GATE)
    return { ...base, pass: false, reason: `identity below threshold (${vsUser.toFixed(3)} < ${GATE})` }
  return { ...base, pass: true }
}
```

```ts
import type { Face } from '@/lib/identity'
export { featherMask } from './mask'
import { featherMask } from './mask'
import { similarityTransform } from '@/lib/identity'

export interface Box { x0: number; y0: number; x1: number; y1: number }

/** Padding factors ported from the validated spike. */
const PAD_X = 1.5, PAD_UP = 1.5, PAD_DOWN = 1.7

export function headBox(f: Face, imgW: number, imgH: number): Box {
  const cx = f.x + f.w / 2, cy = f.y + f.h / 2
  return {
    x0: Math.max(0, Math.round(cx - f.w * PAD_X)),
    y0: Math.max(0, Math.round(cy - f.h * PAD_UP)),
    x1: Math.min(imgW, Math.round(cx + f.w * PAD_X)),
    y1: Math.min(imgH, Math.round(cy + f.h * PAD_DOWN)),
  }
}

/**
 * Align the generated head onto the original crop using uniform scale +
 * translate. NEVER stretch: the models return ~2:3 regardless of input
 * aspect, and stretching distorts the head.
 */
export function blend(
  frameRgb: Uint8Array, frameW: number, frameH: number,
  headRgb: Uint8Array, headW: number, headH: number,
  srcFace: Face, dstFace: Face, box: Box
): Uint8Array {
  const bw = box.x1 - box.x0, bh = box.y1 - box.y0
  const t = similarityTransform(srcFace, dstFace)
  const mask = featherMask(bw, bh)
  const out = Uint8Array.from(frameRgb)

  for (let y = 0; y < bh; y++) {
    for (let x = 0; x < bw; x++) {
      const sx = Math.round((x - t.tx) / t.scale)
      const sy = Math.round((y - t.ty) / t.scale)
      if (sx < 0 || sy < 0 || sx >= headW || sy >= headH) continue
      const a = mask[y * bw + x]
      if (a <= 0) continue
      const di = ((box.y0 + y) * frameW + (box.x0 + x)) * 3
      const si = (sy * headW + sx) * 3
      for (let c = 0; c < 3; c++) out[di + c] = Math.round(headRgb[si + c] * a + frameRgb[di + c] * (1 - a))
    }
  }
  return out
}
```

```ts
/** Feathered ellipse, centred slightly high to favour hair over collar. */
export function featherMask(w: number, h: number, inset = 0.05, blur = 0.18): Float32Array {
  const m = new Float32Array(w * h)
  const cx = w / 2, cy = h * 0.46
  const ax = w * (0.5 - inset), ay = h * (0.5 - inset)
  const feather = Math.max(w, h) * blur

  for (let y = 0; y < h; y++) {
    for (let x = 0; x < w; x++) {
      const d = Math.hypot((x - cx) / ax, (y - cy) / ay)   // 1.0 at the ellipse edge
      const px = (1 - d) * Math.min(ax, ay)
      m[y * w + x] = Math.max(0, Math.min(1, px / feather))
    }
  }
  return m
}
```

```ts
import { TIMING } from '@/lib/template'

export function buildFiltergraph(): string {
  const { width, height, fps, shotDuration: D, crossfade: X,
          panPxPerSec, panSourceWidth, panSourceHeight } = TIMING
  const [o1, o2] = TIMING.offsets()

  // Travel is centred in the horizontal headroom so the crop never runs off.
  const headroom = panSourceWidth - width          // 96px
  const travel = panPxPerSec * D                   // ~49px
  const startX = Math.round((headroom + travel) / 2)
  const yOff = Math.round((panSourceHeight - height) / 2)
  const pan = `crop=${width}:${height}:x='${startX}-${panPxPerSec}*t':y=${yOff}`

  const chains = [0, 1, 2].map((i) =>
    `[${i}:v]scale=${panSourceWidth}:${panSourceHeight}:flags=lanczos,` +
    `loop=loop=-1:size=1:start=0,fps=${fps},${pan},setsar=1,trim=duration=${D.toFixed(3)}[v${i}];`
  ).join('')

  return chains +
    `[v0][v1]xfade=transition=fade:duration=${X}:offset=${o1.toFixed(3)}[x1];` +
    `[x1][v2]xfade=transition=fade:duration=${X}:offset=${o2.toFixed(3)}[vout]`
}
```

```ts
  shots: [string, string, string], audio: string, out: string, opts: RenderOpts
```

```ts
import { MODEL_LADDER, edit as realEdit } from '@/lib/provider'
import { verify as realVerify } from '@/lib/gate'
import { embed, cosine, detect } from '@/lib/identity'
import type { Shot } from '@/lib/template'

export interface SwapDeps {
  edit: typeof realEdit
  verify: typeof realVerify
  embedResult: (img: Buffer) => Promise<Float32Array | null>
}
export interface SwapInput { shot: Shot; face: Buffer; userEmb: Float32Array | null }
export interface SwapOutput {
  ok: boolean; image?: Buffer; vsUser: number; costUsd: number; charged: boolean; reason?: string
}

export async function swapShot(
  input: SwapInput,
  deps: SwapDeps = { edit: realEdit, verify: realVerify, embedResult: async (b) => null }
): Promise<SwapOutput> {
  let spent = 0
  let last = 'no attempts'
  const crop = await loadCrop(input.shot.file)
  const origEmb = await loadOriginalEmbedding(input.shot.file)

  for (const model of MODEL_LADDER) {
    const r = await deps.edit({ crop, face: input.face, model, expression: input.shot.expression })
    spent += r.costUsd
    const resEmb = await deps.embedResult(r.image)
    const v = deps.verify({
      vsUser: cosine(resEmb, input.userEmb),
      vsOriginal: cosine(resEmb, origEmb),
    })
    if (v.pass) return { ok: true, image: r.image, vsUser: v.vsUser, costUsd: spent, charged: true }
    last = v.reason ?? 'rejected'
  }
  // Never charge for a video we could not produce.
  return { ok: false, vsUser: NaN, costUsd: spent, charged: false, reason: last }
}
```

`loadCrop` and `loadOriginalEmbedding` read the template frame, detect the face, cut the head box (Task 6), and cache the original embedding per shot — it never changes, so compute it once at module load.

```ts
export const DAILY_CEILING_USD = Number(process.env.DAILY_CEILING_USD ?? 25)
export const FREE_VIDEOS_PER_DAY = Number(process.env.FREE_VIDEOS_PER_DAY ?? 3)

export function refill(b: { tokens: number; updatedAt: number }, capacity: number, perSec: number) {
  const elapsed = (Date.now() - b.updatedAt) / 1000
  return Math.min(capacity, b.tokens + elapsed * perSec)
}
```

`checkSpendCeiling()` sums today's `spend_ledger` and **throws before any provider call** if the day's total plus the estimated job cost would exceed `DAILY_CEILING_USD`. It fails closed: if the ledger query errors, refuse.
